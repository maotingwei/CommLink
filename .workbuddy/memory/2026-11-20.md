# 2026-11-20 工作日志

## 项目：CommLink — Windows 虚拟串口桥接软件

用户需求：在 Windows 自研内核驱动创建一个虚拟串口，串口助手收发的数据由本软件捕获/注入，
带网页 UI（跨电脑浏览器访问）显示 TX/RX、字符匹配过滤（命中不存储）、搜索、LOG 文件。
板子端物理串口协议后续提供，先做虚拟串口生成 + 数据互发部分。

用户明确选择："自研 Windows 内核驱动"方案（而非 com0com / 纯 TCP）。

### 已完成
- 架构：Legacy WDM 驱动(COM口设备 + 控制设备 \\.\CommLinkCtl，双环形缓冲 TxRing/RxRing)；
  Python 后端(纯标准库 ctypes 直连驱动 + HTTP/WebSocket + 日志/过滤/搜索 + TCP板子预留)；
  网页 UI(配置/实时数据/过滤/搜索/注入RX)。数据方向：TX=串口助手→驱动→服务→板子；RX=反向。
- 文件：README.md、driver/{CommLink.c,CommLinkCommon.h,build_driver.bat}、install_driver.bat、
  server/{app.py,config.json,public/{index.html,style.css,app.js}}、start_server.bat
- 验证：本机 HTTP 7端点全通、WS 握手+实时推送正常、过滤命中不存储/不写日志、JS/Python 语法通过。

### 关键环境事实（重要）
- 本机有 VS2019 BuildTools(MSVC 14.29.30133, D:\Program Files (x86)\Microsoft Visual Studio\2019\BuildTools)
  + Windows SDK 10.0.19041.0，但**未装 WDK**（无 Include\...\km\wdm.h / Lib\...\km）。
  因此 CommLink.sys 无法在本机编译，build_driver.bat 会检测并报错退出。用户需自行安装 WDK 10.0.19041.0 后编译。
- Python 用 C:\Users\Administrator\.workbuddy\binaries\python\versions\3.13.12\python.exe
- Node 用 C:\Users\Administrator\.workbuddy\binaries\node\versions\22.22.2-2\node.exe

### IOCTL 协议（驱动与 Python 共享，勿改错）
CTL_CODE = (0x8A00<<16)|(0<<14)|((0x800+n)<<2)|0
GET_TX=n0, PUT_RX=n1, SET_EVENT=n2, GET_STATUS=n3(7×ULONG=28B), PURGE=n4, GET_VERSION=n5(3×ULONG=12B)
